# Managing Geospatial Data

Source for the **Data Management** module of
[Enabling the Geospatial Turn in the Social Sciences](https://spatialturn.github.io/),
published at <https://spatialturn.github.io/DataManagement/>.

The lesson is built with [The Carpentries Workbench](https://carpentries.github.io/sandpaper-docs/). It is a
theory-based module with no notebooks or data downloads.

| Episode file | Topic |
|---|---|
| `episodes/introduction.md` | Introduction to data management, the data lifecycle and data management plans |
| `episodes/data-models.md` | Vector and raster data models |
| `episodes/file-formats.md` | Geospatial file formats |
| `episodes/crs.md` | Coordinate reference systems |
| `episodes/designing-data.md` | Data dictionaries, field types, domains and keys |
| `episodes/organizing.md` | Folder structures, file naming, versioning and backup |
| `episodes/quality.md` | Spatial data quality |

Figures named `dm_*.png` in `episodes/` were generated with Python from U.S. Census Bureau TIGER/Line and
cartographic boundary files (2024) and OpenStreetMap data ((c) OpenStreetMap contributors, ODbL), or drawn as
diagrams. Each has a `-dark` copy for the site's dark mode.
